# Страви: особистий PWA для вибору й обліку страв

Мова інтерфейсу й коментарів: українська. Користувачка не розробник: пояснюй просто, роби малими кроками.

## Продукт
Мобільний PWA (Android), офлайн, дані локально (IndexedDB через Dexie). Каталог страв з ролями (гарнір / білок / повна страва), варіантами, структурованими інгредієнтами (обов'язкові, групи «або», дозволені заміни), смаковими тегами, часом і прапорцем духовки. Є список «Мої продукти», пошук за наявними продуктами, пари страв, фільтри, сортування, ручний порядок і тимчасове приховування страв.

## Стек
Vite + React + TypeScript, Dexie, react-router (HashRouter), dnd-kit, vite-plugin-pwa. Шрифти локально через @fontsource (у кеш PWA — лише кирилиця й латиниця). Хостинг: GitHub Pages, публікація GitHub Actions (`.github/workflows/deploy.yml`) після push у `main`, `base: './'`. PNG-іконки в `public/` згенеровані з `icon.svg`.

## Стан
Етап 1 готовий: каталог (пілюлі ролей з множинним вибором, пошук, сортування, фільтри, приховування, ручний порядок), екран страви (фото, варіанти, інгредієнти, заміни).
Етап 2, порядок: 1) GitHub Pages і встановлення на телефон (зроблено), 2) додавання/редагування страви (зроблено: `DishForm.tsx`, чернетка й перетворення в `draft.ts`, стиснення фото в `photo.ts`), 3) «Мої продукти» (зроблено: `Pantry.tsx`, вкладки `Tabs.tsx`; порівняння продуктів без урахування регістру через `pantrySet`/`norm`), 4) експорт/імпорт даних (зроблено: кнопка вгорі каталогу, `Backup.tsx` + `backupData.ts`), 5) пошук за наявними продуктами (зроблено: `Search.tsx`, логіка `coverage`/`bestMatch` у `logic.ts`), 6) пари.

## Дизайн «Тихий фаянс»
Білий фон, кобальт `#3149B8`, текст `#1F2A5C`, приглушений `#4A5690`, світлі фони `#EEF1FB`. Шрифти Unbounded (заголовки) + Onest. Ліній-фестон під заголовком. Асиметричні радіуси (`22px 22px 4px 22px` тощо). Пілюлі, а не вкладки.
- Роль кодується формою, кольором і значком, не лише кольором: гарнір — жовтий квадрат, білок — помаранчеве коло, повна — блакитна арка.
- Фото страв у різних формах і пастельних фонах, значок ролі внизу праворуч, духовка — іконка вгорі праворуч.
- У рядку каталогу: назва, «Потрібно: обов'язкові», «немає: …» окремим рядком. Час і кількість інгредієнтів показуються лише при відповідному сортуванні. Категорію текстом не пишемо.
- Мінімум 44px для цілей натискання, кнопки з aria-label.

## Рішення
- Духовка — булевий прапорець, без температури.
- Група інгредієнтів (`group`): достатньо одного з групи («кріп або петрушка»).
- Приховування поки ручне повернення (`hiddenAt`).
- Фото зберігається як Blob в IndexedDB, стиснуте до 1280 px (JPEG).
- У формі група «або» — один пункт із кількома назвами; назва групи в базі генерується з назв (`кріп/петрушка`).
- Роутер — `createHashRouter` (потрібен для `useBlocker`: питання «Вийти без збереження?» на кнопку «назад»).
- Видалення страви — назавжди, з підтвердженням; також прибирає її з `pairs` інших страв.
- Пошук «Що приготувати» бере продукти з «Моїх продуктів». Заміна, що є вдома, закриває інгредієнт (у каталозі такий інгредієнт теж не потрапляє в «немає»). Для страви з варіантами береться варіант, де бракує найменше. «Хочу використати» — продукти мають бути інгредієнтами варіанта (заміни не рахуються). Посилання `/dish/:id?v=<id варіанта>` відкриває страву з цим варіантом.
- Резервна копія: один JSON (`app: "stravy"`, `version: 1`), фото всередині як data-URL. Імпорт **замінює все** (після підтвердження, з пропозицією спершу зберегти поточне); id страв зберігаються, бо на них посилаються `pairs`. Файл новішої версії не приймається.
- Приклади додаються лише раз: позначка `seeded` у таблиці `meta` (Dexie версія 2). Якщо видалити всі страви, приклади не повертаються.
- Файли не можна називати так, щоб вони відрізнялися лише регістром (`backup.ts` і `Backup.tsx`): на Windows це конфлікт.

## Команди
`npm install`, `npm run dev`, `npm run build` (тип-перевірка + збірка).
