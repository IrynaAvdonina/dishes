## Що вміє

- **Каталог страв** з ролями: гарнір, білок, повна страва. **Сніданки** — окремим розділом, перемикач угорі каталогу. Роль видно за формою й кольором значка: жовтий квадрат, помаранчеве коло, блакитна арка.
- **Пошук, сортування й фільтри**: за назвою чи продуктом, наявністю продуктів, часом, складністю, улюбленістю, духовкою, смаком. Можна розставити страви вручну перетягуванням або тимчасово сховати.
- **Сторінка страви**: кілька фото, варіанти («з картоплею», «у томатному соусі»), інгредієнти з позначкою «є / немає», заміни (вершкове масло → олія), групи «або» (кріп або петрушка).
- **Додавання й редагування** своїх страв, оцінки: ★ складність і ♥ наскільки подобається.
- **Мої продукти**: що є вдома, а стрілка показує всі продукти зі страв, яких немає. Наявність можна позначати й прямо на сторінці страви. Тут же керуєте своїм списком смаків.
- **Що приготувати**: страви, для яких усе є, і ті, де бракує одного-двох продуктів, з урахуванням замін.
- **Список покупок**: додавайте вручну або одним натисканням усе відсутнє зі сторінки страви. Позначили «куплено» — продукт сам з'являється в «Моїх продуктах».
- **Резервна копія** в один файл (разом із фото), щоб перенести дані на інший телефон.

Базове, що є вдома завжди (сіль, олія, цукор, чорний перець, паприка, лавровий лист), в інгредієнтах не пишеться.

## Як встановити на телефон

1. Відкрийте [irynaavdonina.github.io/dishes](https://irynaavdonina.github.io/dishes/) у Chrome на Android.
2. Меню ⋮ → **«Додати на головний екран»** або **«Установити додаток»**.
3. Запускайте зі значка: застосунок відкривається на весь екран і працює без інтернету.

Оновлення приходять самі, коли застосунок відкрито з інтернетом.

## Де зберігаються дані

Тільки в браузері на вашому пристрої (IndexedDB). На сервер нічого не надсилається.
Щоб не втратити страви, час від часу зберігайте копію: каталог → кнопка резервної копії вгорі (стрілка в лоток) → **«Зберегти у файл»** або **«Надіслати файл»**.

Під час першого запуску в застосунку з'являється базовий набір: 41 страва на обід і вечерю та 16 класичних сніданків. Його можна змінювати й видаляти, а повернути — через «Резервна копія» → «Базовий набір страв».

## Для розробки

```bash
npm install
npm run dev      # локальний сервер
npm run build    # перевірка типів і збірка в dist/
```

Стек: Vite, React, TypeScript, Dexie (IndexedDB), React Router, dnd-kit, vite-plugin-pwa. Шрифти Unbounded і Onest вбудовані в застосунок.

Після кожного `push` у гілку `main` GitHub Actions збирає застосунок і публікує його на GitHub Pages ([.github/workflows/deploy.yml](.github/workflows/deploy.yml)).

Нотатки про рішення й дизайн «Тихий фаянс» — у [CLAUDE.md](CLAUDE.md).
